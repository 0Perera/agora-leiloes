Como a verificação funciona

  1. 1Cada lance recebe um código calculado a partir dos dados dele e do código do lance anterior. Assim, um lance fica preso ao outro.
  2. 2Quando o lote encerra, o código do último lance vira o selo do lote. Se lances forem apagados do fim, o selo deixa de conferir.
  3. 3Ao abrir esta página, conferimos todos os códigos de novo. Qualquer lance alterado, apagado ou incluído depois aparece aqui, no ponto exato.
